# D11 Foundation integration boundary

D11 Foundation owns deterministic deployment, release, publishing-state, health, domain, log, rollback, unpublish and local fixture-export presentation. The Code OSS workbench receives an injected D1 deployment provider read result and has no production origin, publishing route or mutation client.

The following remain blocked:

- D7: canonical project working-set and verified snapshot identity;
- D11 Track B: authoritative publish-source normalization and production publish, update, unpublish and rollback mutations;
- D11 Track B: authenticated domain creation, DNS verification, certificate activation and removal;
- D11 Track B: production deployment logs, health normalization, retention and export authorization.

Future verified-snapshot and Git-revision source classifications fail closed. Retired Buildr101 publish, domain, environment and runtime routes are forbidden.
