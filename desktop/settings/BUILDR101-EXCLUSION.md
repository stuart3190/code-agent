# Retired Buildr101 exclusion

D12 does not import, mount, call, or reproduce retired Buildr101 project-secret, project-integration, project-environment, owner-console, SaaS-payment, Meta-connector, capability-runtime, legacy Stripe, connector, or runtime-worker systems.

The D12 implementation is a desktop-only deterministic contract and presentation layer. Any future production integration must use approved current Thrallo service interfaces and pass the D0 denylist guard.
