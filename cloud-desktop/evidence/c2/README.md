# C2 shell-hardening evidence

These files are browser-rendered evidence from the real fixture-only Thrallo Cloud Desktop implementation. They are not static mockups and make no runtime, backend, Daytona, Builder V2, or production claim.

The Chromium capture set covers the normal desktop, overlapping windows, both half snaps, maximized state, launcher with a running window, waking and reconnecting states, tablet portrait and landscape, mobile app switching, a 200%-equivalent narrow CSS viewport, and dark-theme compatibility.

`verification.json` records the deterministic test, guard, build, cross-browser, accessibility, and reducer-performance evidence for this C2 package.
